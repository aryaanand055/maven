# Maven Project for Azure DevOps Build Pipeline

This project is configured with Maven and Java 17, including an Azure Pipelines build definition (`azure-pipelines.yml`).

## Structure
- `src/main/java/org/example/Main.java`: Main Java application class
- `src/test/java/org/example/MainTest.java`: Unit tests
- `pom.xml`: Maven configuration targeting Java 17
- `azure-pipelines.yml`: Azure DevOps pipeline configuration using `Maven@3` task
